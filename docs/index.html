01 The question

Can a small UAV team learn to find and put out fires it cannot fully see?

A seeded simulator for multi-agent reinforcement learning over a real study box in Victoria, with metrics computed from state and nothing invented.

Research simulation. Not an operational fire-behaviour or UAV command system.

02 What the laboratory does

A supervisor-facing workbench for seeded, comparable episodes

The user selects a real WGS84 study envelope in Victoria, places ignition points, sets wind and fuel, sizes the fleet and its sensor, then runs the same scenario under a scripted expert or a loaded MARL checkpoint. Every dashboard number is derived from simulation state. Undefined values return null and display as N/A.

The same scenario JSON and seed reproduce the same trajectory. Multi-seed comparison runs headless and reports mean, sample SD and a Student-t 95% interval. The API marks significance_tested: false; no hypothesis test is performed, and the report does not claim one.

Study areas

Kinglake / Central Highlands, Grampians, East Gippsland, Otway Ranges, Alpine foothills. Each is a searchable envelope, not a legal boundary. Kinglake is about 5.5 by 8 km.

Policies

Three trained actors: independent DQN, MAPPO, MADDPG. A greedy nearest-known-fire expert stays available for training rollouts. A missing checkpoint is labelled untrained and acts randomly.

Views and exports

MapLibre 2D by default; Cesium 3D lazy-loaded from the same SimState. Per-step WebSocket ticks, an engine event log, replay, JSON and CSV export.

03 One environment, two paths

Training and deployment call the same WildfireEnv.step()

Visualisation is never required to train. The headless trainer and the FastAPI service run the identical NumPy environment, so a checkpoint evaluated offline behaves the same on the map.

Coordinate discipline

WGS84 for storage and display. All distances, headings and grids use a local azimuthal-equidistant metre frame with origin at the AOI centroid. Nothing is measured in raw latitude and longitude.

Clock discipline

Fixed timestep dt, default 1 s. The UI speed multiplier changes wall-clock sleep only. The displayed clock is environment.time_s.

04 Fire model

A simplified elliptical cellular automaton, labelled as such

Cells are UNBURNED, BURNING, BURNED, UNBURNABLE or EXTINGUISHED. Only UAV suppression produces EXTINGUISHED; natural burnout is BURNED. Detection never changes a cell.

Head rate of spread

Elliptical scaling toward a neighbour

R(φ) = Rhead · (1 − e) / (1 − e · cos φ) e = clip((LB − 1)/(LB + 1), 0, 0.95) LB = 1 + c · U

heading to neighbour relative to downwind

0.25 (length-to-breadth vs wind)

Ignition

stochastic: p = 1 − exp(−R(φ)/d · dt) deterministic: Σ R(φ)/d · dt ≥ 1 (Huygens-style arrival)

Stochastic mode draws from numpy.random.Generator(seed). Deterministic mode accumulates exposure per unburned cell.

Burnout and slope

Tburn = T0 / max(fuel, 0.15), T0 = 180 s

Slope multiplies rate of spread only when a DEM is loaded and slope_is_real is set. Bundled runs use slope = 0.

05 Aircraft, sensing, suppression, comms

Point-mass aircraft, Bernoulli sensing, overlap-only suppression

UAV dynamics

Kinematic point mass in the local ENU frame. Speed, climb rate and turn rate are clipped to configured maxima; position is clipped to the AOI. Wind does not advect the airframe, by documented simplification.

P = Phover + k · v² batteryJ −= P · dt return to base when batteryJ / capacity ≤ threshold
capacity
180 kJ default
cruise
16 m/s at 120 m in evaluation

Sensor

A true detection of a source needs a BURNING cell inside range and a successful Bernoulli trial. With no fire in range, a false report is emitted with probability p_fp. No line-of-sight, smoke or weather attenuation.

ptrue = pdet · (1 − pfn) · clip(0.25 + 0.75 · I, 0, 1)
range
800 m in evaluation
I
cell intensity, 0 to 1

Suppression

Detecting a fire does not put it out. A UAV extinguishes a source only when its planimetric distance to the fire point is at most suppression_range_m, default 120 m. Then every remaining BURNING cell of that source becomes EXTINGUISHED and the source stops spreading.

Communication, coverage, separation

An undirected link exists when distance is within both ranges and both batteries are positive; drops are i.i.d. Coverage is explored eligible cells over eligible cells. Near miss below the configured separation with |Δz| under 15 m; collision below 8 m horizontal.

06 What an agent sees and does

Partial observability at execution, a team reward in training

Each UAV acts from a 57-element observation and picks one of nine discrete actions. Known fires at execution are the agent's own true detections plus successfully delivered messages, never the global list, unless allow_global_state is switched on for training.

Observation, length 57, float32

  • 0 to 10Own pose, battery, wind, normalised time. Heading as sin and cos; positions over AOI extent; wind over 40 m/s.
  • 11 to 19Up to three known active fires as (dx, dy, intensity). Extinguished and burned-out sources are dropped so the agent seeks what remains.
  • 20 to 31Up to three UAVs inside communication range.
  • 32 to 565 × 5 local coverage patch.

Action, discrete-9

Mapped to a target heading at cruise speed, then constrained by apply_action. HOVER at a fire extinguishes only inside suppression range.

07 Training pipeline

Clone the expert, then fine-tune without forgetting how to hover

An earlier short run learned to approach fires but not the final hover that completes suppression. The current trainer is built around that failure. Steps are ordered; each depends on the previous.

  1. STEP 1

    Expert rollouts

    Greedy nearest-known-fire policy generates trajectories with fires visible. Lawnmower is not cloned; it does not teach suppression.

  2. STEP 2

    Behavioural cloning

    Near-fire HOVER is oversampled. Cloning repeats until the holdout extinguished count is measured at 1.5 to 2 or better. Adam, lr 8e-4, 12 epochs, batch 256.

  3. STEP 3

    MAPPO and MADDPG fine-tune

    Central critic, decentralised actor. A BC regulariser and decaying expert mixing keep the suppression behaviour. Actor lr 8e-5, critic 2e-4; MADDPG uses Gumbel-Softmax τ 0.8 and target τ 0.02.

  4. STEP 4

    Keep the best holdout

    The saved checkpoint is the one with the highest measured holdout extinguish count on seeds 9000 to 9002. Nothing is written that was not measured.

Actor network

57 → 128 → 128 → 9 tanh · tanh · logits critic (MAPPO): 4 × 57 → 128 → 128 → 1 Q (MADDPG): 4 × (57 + 9) → 128 → 128 → 1

08 Measured results

Fires extinguished out of four, two seeds, Kinglake

Headless evaluation from scripts/eval_policies.py: six UAVs, four random ignitions, 240 s, wind 18 km/h from NW, sensor 800 m, suppression 120 m, seeds 101 and 202. Two seeds is a smoke test, not a study; the interactive compare panel defaults to three seeds so a laptop finishes during a demonstration, and a paper run should raise this to 30.

What changed between checkpoint sets. Before the current recipe, MAPPO extinguished 4 then 2 sources and posted a reward of −904 on seed 202, a collision-penalty signature. DQN managed 2 then 0. After adding HOVER oversampling, the BC regulariser and best-holdout selection, MAPPO reached 4 of 4 on both seeds and DQN 3 and 4. A later MADDPG-only re-evaluation (eval_maddpg.json) also recorded 4 of 4 on both seeds.

Read with care. Every policy detected all four fires; detection is the easy half. Under allow_global_state=True the scripted baselines converge on the same fire-seeking trajectories as the greedy expert, so this table cannot separate them, and the learned actors are matching the expert they were cloned from rather than exceeding it. Whether they generalise where the expert does not is the open question for the next experiment.

09 Rules of evidence

Conventions the codebase enforces so numbers can be trusted

  • Metrics come from state. Every dashboard value is computed in metrics.py from the live environment. Undefined returns null, shown as N/A.
  • Detection is not suppression. A green pin is a detection report. Extinguished counts require a UAV inside suppression range of a burning cell.
  • Untrained is labelled. A missing or incompatible checkpoint yields UntrainedMARLPolicy with trained=False. It is never reported as a MARL result.
  • Real and simulated layers are separate. AOI envelopes and imagery tiles are labelled real. Fire, UAV and coverage layers are labelled simulated. Missing datasets are placeholders, not invented roads or terrain.
  • Reproducibility is tested. Scenario JSON plus seed plus policy fixes the trajectory. 33 tests across 11 files cover fire, sensor, suppression, coverage, communication, collision, metrics and identity of repeated runs.
  • No unearned significance. Multi-seed reports print mean ± SD with a t-interval and set significance_tested: false. Coordination-efficiency slogans without a formula are not implemented.

10 Limitations and next steps

What the model is not, and what would move it forward

Documented simplifications

  • Fire: elliptical cellular spread, not Phoenix, SPARK, Prometheus or FARSITE.
  • UAV: kinematic point mass; no wind drift, rotor dynamics or airspace rules.
  • Sensor: planimetric range plus Bernoulli; no terrain occlusion, smoke or camera model.
  • Suppression: overlap rule with fixed intensity decay; not a retardant or water-drop model.
  • Communication: geometric range with i.i.d. drops; not a radio channel.
  • Fuel uniform, slope zero, wind constant, unless the user supplies GeoJSON or a DEM. 3D mode renders an ellipsoid.

Proposed next experiments not yet run

  • Evaluate at 30 seeds with the t-interval, holding scenario fields fixed except policy and seed.
  • Withhold allow_global_state at evaluation so learned actors must rely on own detections and delivered messages, where the greedy expert has no privileged view.
  • Vary ignition count, wind and communication drop rate to find where cloning of the expert stops holding.
  • Add a vegetation fuel layer and DEM slope for Kinglake so the fire model uses real inputs.
  • Report per-fire detection time and time to first detection alongside suppression counts.
